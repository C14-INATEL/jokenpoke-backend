## User Story

> **Como** desenvolvedor do projeto `jokenpoke-game-api`,  
> **eu quero** que o ambiente de testes execute sem warnings de depreciação e que a injeção de dependências siga o padrão moderno do FastAPI com `Annotated`,  
> **para que** a suíte de testes seja confiável e silenciosa, o código esteja em conformidade com as boas práticas do stack e a manutenção futura seja facilitada.

---

## Contexto / Motivação

Dois problemas de qualidade técnica foram identificados e tratados nesta história. O primeiro é um warning de depreciação emitido durante a execução dos testes, causado pela incompatibilidade entre a versão do `httpx` e o `TestClient` do FastAPI/Starlette — resolvido com a adição de `httpx2` (PR #29). O segundo é o uso do padrão legado de injeção de dependências (`Depends()` direto nos parâmetros), apontado pelo SonarLint, que foi substituído pelo padrão moderno com `Annotated` para consistência e legibilidade (PR #30). Ambas as alterações são invisíveis ao usuário final, mas essenciais para a saúde e escalabilidade do projeto.

## Critérios de Aceitação

### AC-01 — Execução da suíte de testes sem warnings de depreciação do TestClient

```gherkin
Given  as dependências do projeto instaladas via "poetry install"
When   a suíte de testes é executada com "poetry run pytest"
Then   nenhum warning relacionado ao uso de "httpx" com "starlette.testclient"
       deve ser exibido na saída do terminal
And    todos os testes existentes devem continuar passando
```

---

### AC-02 — Compatibilidade do httpx2 com o stack FastAPI/Starlette

```gherkin
Given  a dependência "httpx2" adicionada ao "pyproject.toml"
When   o ambiente é configurado com "poetry install"
Then   não deve haver conflito de dependências
And    o "TestClient" do FastAPI deve funcionar corretamente nos testes de integração
```

---

### AC-03 — Injeção de dependências padronizada com Annotated

```gherkin
Given  qualquer rota ou arquivo de dependências do projeto
When   o código é inspecionado ou analisado por ferramenta de análise estática (SonarLint)
Then   nenhum uso do padrão legado "Depends()" diretamente em parâmetros de função
       deve estar presente
And    todas as dependências devem ser declaradas com o padrão "Annotated[Tipo, Depends(...)]"
```

---

### AC-04 — Endpoints de autenticação funcionais após refatoração

```gherkin
Given  o backend iniciado com "make run"
When   o cliente envia POST /auth/register com dados válidos
Then   a resposta HTTP deve ser a esperada sem erros de runtime
When   o cliente envia POST /auth/login com credenciais válidas
Then   a resposta HTTP deve ser 200 com "access_token" retornado
And    nenhuma regressão funcional deve ser introduzida pela refatoração
```

---

### AC-05 — Ausência de warnings de análise estática após refatoração

```gherkin
Given  o código refatorado no PR #30
When   a análise estática é executada via SonarLint ou ferramenta equivalente
Then   nenhum warning sobre uso legado de "Depends()" deve ser reportado
       nos arquivos de rotas e dependências do projeto
```

## Notas Técnicas

- Esta história não altera **nenhum comportamento visível ao usuário final** — trata-se exclusivamente de qualidade interna do projeto.
- A adição de `httpx2` resolve o warning, mas não substitui `httpx`; ambas coexistem, sendo `httpx2` o pacote que provê a compatibilidade necessária para o `TestClient` com versões recentes do Starlette.
- A refatoração com `Annotated` é **retrocompatível**: nenhuma mudança de contrato de API foi introduzida.
- Esta história complementa a US-002 (PR #28), pois o `conftest.py` de integração criado naquela história se beneficia diretamente da correção do `TestClient` feita aqui.
